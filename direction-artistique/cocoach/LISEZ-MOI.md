# Cocoach : illustrations

- `references/` : la fiche personnage et la planche de contrôle (documents de travail,
  jamais affichés dans le jeu). Elles servent à vérifier que chaque nouvelle image
  respecte le personnage.
- `ancien/` : les illustrations provisoires remplacées le 27 novembre 2026 (sauvegarde).
- Les images utilisées par le jeu sont dans `public/cocoach/` :
  - `cartes/` : commune, rare, epique, legendaire, champion, presentation
    (1024 × 1536, format 2:3, bandeau de rareté imprimé en bas de l'image) ;
  - `expressions/` : neutre, content, malin, vaincu, vainqueur, arrogant, mefiant
    (512 × 512, carrées).
- Pour changer une image : remplacer le fichier dans `public/cocoach/`, même nom,
  mêmes proportions.
